# ☕ Starbucks Sales Analysis & Retail Performance Dashboard

## 🔗 Project Links
* **Live Interactive Dashboard:** [View on Tableau Public](https://public.tableau.com/shared/QJC2XZCP8?:display_count=n&:origin=viz_share_link)

## 📌 Project Overview
An interactive retail intelligence dashboard built to evaluate sales trends, product categories, and regional market performance for Starbucks Corporation. 

## 💼 Business Problem Solved
Formulated clear data pathways to pinpoint seasonal sales fluctuations, underperforming product segments, and top-selling store items for better corporate retail decision-making.

## 🛠️ Technical Skills Implemented
* **Data Visualization:** Tableau Public
* Configured calculated fields for critical retail Key Performance Indicators (KPIs).
* Designed advanced filtering options for regional parameters.
* Focused heavily on a clean, professional executive dashboard layout.

## 📊 Key Visualizations & Insights
* **Trend Breakdowns:** Identified seasonal revenue spikes across product categories.
* **Menu Analytics:** Matrix sheets isolating top revenue-generating menu items.
